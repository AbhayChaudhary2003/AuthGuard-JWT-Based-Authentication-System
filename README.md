# 🔐 JWT Authentication System

A simple authentication system built with **Node.js, Express.js, MongoDB, and JWT**.

## Features

* User Registration
* User Login
* Password Hashing
* JWT Authentication
* Protected Routes
* MongoDB Integration

## Tech Stack

**Node.js | Express.js | MongoDB | Mongoose | JWT | bcrypt**

## Setup

```bash
npm install
npm run dev
```

Create a `.env` file:

```env
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
PORT=3000
```

Add `.env` to `.gitignore` to keep your secrets private.
